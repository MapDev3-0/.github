## Groundy とは

Groundy は、登記所備付地図（法務局の地図データ）をもとに、全国の地番や土地の境界を地図の上で確認できるデジタル地図サービスです。
地番の確認から、土地情報の記録、チームでの共有まで、山林・土地の管理に必要なことを Web とスマホアプリでまとめて行えます。

## 主な機能

- **地番・境界線の確認** — 地番や住所から土地を探し、区画の境界を地図で確認
- **Groundy Drive** — 地番・メモ・管理項目などの土地情報を保存して整理
- **グループ管理** — メンバーと土地情報を共有し、管理者・編集者・閲覧者の権限を分けて共同管理
- **地図の重ね合わせ** — 森林計画図、地形・防災情報、3D表示などを切り替えて表示
- **ツール** — 面積・距離の測定、植林点の自動生成、オフライン地図のダウンロード
- **印刷・出力** — 縮尺を指定した地図の PDF 出力
